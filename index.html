Agentic Workflow Engine
dag-based workflow orchestrator

A backend engine that runs a customer-support triage workflow as a DAG — Postgres as the single source of truth for every node's state, crash-safe replay, idempotent retries, and a park-and-resume flow for the human-in-the-loop step.

GoPostgresREST API
  • Built a central executor that drives stateless nodes through a generic Execute interface, reading Postgres on every dispatch so a live run and a post-crash resume share the exact same code path.
  • Modeled execution as a fixed-point loop — read state, dispatch whatever's unblocked, repeat — so branching, skipped paths, and retries fall out of the state machine naturally instead of being special-cased.
  • Made human approval fully non-blocking: the node parks as awaiting_approval in Postgres and releases the goroutine, letting a run sit paused for days without holding any resources.
  • Derived idempotency from checking node_states before acting, so a retried or duplicate call is a no-op rather than a double-execution of an external system.
